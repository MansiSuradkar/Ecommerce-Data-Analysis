# Ecommerce-Data-Analysis
## Project Overview

This project analyzes customer purchasing behavior using the **Online Retail Dataset** from Kaggle. The objective is to identify sales trends, customer purchasing patterns, product performance, and revenue insights to support data-driven business decisions.

The project demonstrates end-to-end data analytics using **Python, SQL, and Power BI**.

---

## Dataset

- Dataset: Online Retail Dataset
- Source: Kaggle
- Records: ~541,000 transactions
- Features:
  - Invoice Number
  - Stock Code
  - Product Description
  - Quantity
  - Invoice Date
  - Unit Price
  - Customer ID
  - Country
